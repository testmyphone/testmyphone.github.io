Some browsers, particularly Safari on iOS, don't expose every hardware API to web pages — Bluetooth pairing and USB access are common examples. When that happens TestLab marks the test "Not supported on this browser" rather than reporting a false failure.
Most hardware APIs (microphone, camera, geolocation, sensors) require a "secure context" — either https:// or localhost.
